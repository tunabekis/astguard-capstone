Project Description software supply chain security

Modern enterprise systems and mission-critical defense infrastructures heavily incorporate third-party and open-source software libraries, inadvertently creating massive exposure to high-impact software supply chain compromises. Contemporary Software Composition Analysis (SCA) solutions depend on historical Common Vulnerabilities and Exposures (CVE) databases. Consequently, they fail to safeguard development pipelines against zero-day malicious additions, sophisticated stealth backdoors, and covert Command-and-Control (C2) communication channels embedded into reputable dependencies. The ASTGuard project aims to architect and validate an automated, privacy-preserving static security framework engineered to discover intentional backdoor semantics and supply chain tampering in Java libraries before package deployment.

Rather than relying on vulnerable, non-compliant third-party cloud APIs or shallow string heuristics, ASTGuard implements a two-stage deterministic analysis pipeline. First, an Abstract Syntax Tree (AST) engine built on JavaParser prunes large codebases down to security-sensitive execution nodes—isolating raw network socket instantiations, operating system command invocations (ProcessBuilder, Runtime.exec), and dynamic class reflection mechanisms (Class.forName, Method.invoke). Second, these isolated code sub-trees and their structural context are classified by an on-premises, fine-tuned open-source code model (such as DeepSeek-Coder or CodeLlama). This hybrid design eliminates intellectual property leaks in air-gapped environments while dramatically suppressing false positives through structural code intelligence.

Key Architectural Innovations

AST Syntax-Aware Sink Pruning

Converts raw Java source trees into contextual graphs to pinpoint remote socket bindings, obfuscated strings, and anomalous OS execution paths.

Air-Gapped On-Premises Inference

Fine-tunes lightweight code LLMs for local evaluation, fulfilling defense-industry compliance with zero external data exfiltration.
