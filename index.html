Project Description

Modern software engineering heavily relies on third-party open-source components, which introduces significant software supply chain security risks. Conventional dependency auditing tools primarily cross-reference packages against databases of publicly disclosed vulnerabilities (CVEs), rendering them ineffective against zero-day supply chain attacks where malicious actors compromise upstream dependencies by injecting subtle backdoors, obfuscated logic, or unauthorized execution routines. ASTGuard addresses this critical security gap by establishing an automated static analysis engine specifically engineered to inspect open-source Java dependencies (JARs and Maven artifacts) prior to their integration into critical software codebases.

The system operates through a specialized hybrid pipeline. First, it parses source and decompiled bytecode into Abstract Syntax Trees (AST) using Java static analysis frameworks, isolating suspicious syntax sub-trees that exhibit high-risk operational behaviors such as dynamic reflection, runtime system execution, native process spawning, and anomalous socket transmissions. Second, rather than assessing entire codebases uniformly, ASTGuard extracts these targeted sub-trees along with library functional metadata and feeds them into a locally hosted, fine-tuned open-source code language model. By correlating syntactic intent with structural behavioral patterns, the model identifies zero-day backdoors, data exfiltration mechanisms, and unauthorized Command & Control (C2) routines with high precision, ensuring strict data privacy and preventing automated dependency poisoning in enterprise environments.
